# hira

The website for Hira: a quarter-acre of land high above the hills of Los Angeles, and a promise from Astralab.

## Pages
- `index.html`: the homepage (the cave, the timeline, the builders, the possibilities)
- `timeline.html`: the full timeline
- `archive.html`: the first vision, as written in July 2026
- `register.html`: the volunteer sign-up form
- `img/`: photos

## Publishing
The site is plain HTML, served by GitHub Pages from the `main` branch.
